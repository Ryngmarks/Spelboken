# Research handoff – tactics boards (full report: docs/research/TACTICS-BOARDS.md)

Tactix: draw a run → Bézier path, constant speed, no keyframes. TacticSlate: frames with ghost positions, no account. Censabella/TacBoard: curve control per path, one-tap formations, connection lines that follow players. Hudl Coach Mode: drawings clear on play. FIFA brief: telestration +25–30% tactical recall (n=14, over-annotation risk).
**Found (OBSERVED):** XPS Playbook has path speed/delay and frame management; Tacticsboard web = keyframes + link share + GIF.
**Not found:** TacticalPad/Tactics Manager/Hudl/Metrica animation mechanics; any product with ball auto-following the passer; any on-board "what this role does" explanation; independent usability reviews or forum complaints (only: Playmaker X wants a pause tool).
**Top recommendation (HYPOTHESIS):** make each new step start as a copy of the previous end positions, and let dragging a player draw its run (arrow = animation data, optional one-handle curve); auto-move the ball with a pass.
**Avoid:** drag-every-player keyframing, huge tool palettes, over-annotated player view, accounts/paywall before first success.
**Open questions for the owner:** Should the ball always follow passes automatically? Are per-arrow delay/speed needed in v1 or is one global speed enough? Should role explanations be per scenario step (caption per player) or per position in the squad?
**Evidence limits:** tacticalpad.com, soccertutor.com (429), Hudl support (404) gave little or nothing; Reddit/forums unreachable; rankings are reasoning, not tested; prices are listing text.
