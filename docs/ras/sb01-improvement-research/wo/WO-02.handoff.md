# WO-02 handoff – Editor chrome on phones

**Status:** DONE · Claude Sonnet 5.5 (ras-implementer) · 2026-10-29

- **Investigated / changed:**
  - Topbar, toolbar and timeline buttons are now ≥ 44 × 44 px (`.editor .btn`, `.tool`, `.step`, timeline arrows `min-width: 44px`).
  - Toolbar is one horizontally scrolling row (`overflow-x: auto`, `flex: none`). Labels are always visible; the old `.tool span {display:none}` is gone. Short labels "+ Eget" / "+ Motst."; `aria-label` keeps the full names.
  - At ≤ 900 px the aside becomes a bottom sheet ("Scenario" button in the sub-bar, backdrop, "Stäng" button, Esc closes, focus moves to "Stäng"). It holds selection details, scenario settings and formation. The button shows an accent dot when something is selected. At > 900 px the side panel is unchanged.
  - The active-tool hint stays. New "?" button toggles a shortcut list (tool keys from `TOOLS` + Ctrl+Z / Ctrl+Y / Delete / Esc).
  - "Roll" is now a dropdown "KOD – Fullt namn" from `POSITION_INFO`, plus "Ingen" and "Egen…". "Egen…" shows a free-text input (max 4 chars, uppercased). Existing non-standard labels open in custom mode.
- **Decisions taken:**
  - Player fields: Nummer and Lag share one row; Roll gets its own full-width row because the full names don't fit the old 3-column grid.
  - The tool set is unchanged, as the WO says.
  - The guide toggles (Korridorer/Tredjedelar, 32 px high) are not in topbar/toolbar/timeline, so I left them at 32 px.
  - `.btn` min-height is scoped to `.editor`, so the library and player views are unchanged.
- **Files:** changed `src/components/Editor.tsx`, `src/styles.css`; new this handoff.
- **Tests:** `npm test` → 74 passed (10 files). `npm run build` → OK. Chrome (playwright-core, `vite preview` on port 4391, stopped afterwards):
  - 375 × 700: all 17 topbar/toolbar/timeline buttons ≥ 44 × 44; `scrollWidth` 375 = viewport; all 8 tool labels displayed; side panel hidden. The sheet opened with the button and closed with Esc.
  - 1280 × 800: all 17 buttons ≥ 44 × 44; `scrollWidth` 1280; side panel visible; the Scenario button is hidden.
  - Role dropdown: 12 options with full names. HY applies to the pitch label. "Egen…" + "lb" gives "LB".
  - Screenshots viewed: 375 px main and 375 px sheet with custom role. 1280 px was measured only; its screenshot was not inspected.
- **Known problems:**
  - At 375 px the toolbar scrolls: "Dribbling" is cut off at the edge and Press/Yta/+ Eget/+ Motst. are off-screen until scrolled (observed). The scroll position is the only cue.
  - The sheet has no focus trap. Esc and Stäng work (observed).
  - A selected player does not open the sheet automatically; the dot on "Scenario" is the cue (a UX choice, not tested with coaches).
- **Open questions:** Should the sheet open automatically on selecting a player (cheaper to find, but covers the pitch)? WO-06 will replace the tool set; the scroll row may then be unnecessary.
- **Recommended next step:** Reviewer check, then merge before WO-06 (shared `Editor.tsx` / `styles.css`).
